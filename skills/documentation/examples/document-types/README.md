# Documentation examples for Text Workshop

These completed pages demonstrate distinct document intents using one fictional
newline-counting fixture. Start with the [product README](readme.md), then choose
the page that matches the reader's task.

| Intent | Example | Review focus |
| --- | --- | --- |
| Learn a prepared activity | [Tutorial](tutorial.md) | Visible results and a complete learning path |
| Learn across pages | [Multipart tutorial](multipart-tutorial/index.md) | Starting state, order, continuation and group outcome |
| Perform a task | [How-to](how-to.md) | Exact steps and observable success |
| Look up a contract | [Reference](reference.md) | Accurate input, output and errors |
| Understand a concept | [Explanation](explanation.md) | Model, relationships and limits |
| Orient in a project | [README](readme.md) | Purpose, initial task and navigation |
| Operate a check | [Runbook](runbook.md) | Preconditions, stop condition and recovery owner |
| Understand a decision | [ADR](adr.md) | Dated rationale, alternatives and consequences |
| Assess a release | [Release notes](release-notes.md) | Reader impact and supported release claims |
| Track code changes | [Code changelog](code-changelog.md) | Behavior changes and supporting source |
| Track documentation | [Documentation changelog](documentation-changelog.md) | Page changes and reader benefit |
| Follow an argument | [Article](article.md) | Evidence, inference and limits |

The [evidence directory](evidence/README.md) supplies source and explicitly
fictional decision/release records. The [verification record](verification.md)
records execution scope and limitations. These examples use their base references
directly; the document-type router supplies the agent's selection layer.
