# Inspect and count the complete sample

Begin with the checked-in Text Workshop samples and the tools listed on the
[activity entry page](index.md). Run commands from the parent document-types
directory. This page ends with a visible sample and a count of 2.

## Inspect the sample

Run:

```bash
cat evidence/sample.txt
```

Observe alpha on one line and beta on the next.

## Count the sample

Run:

```bash
bash evidence/count_lines.sh evidence/sample.txt
```

The count is 2. Keep that result in mind as you
[compare the unterminated sample](02-unterminated-sample.md).
