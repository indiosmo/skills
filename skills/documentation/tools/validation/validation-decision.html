Decision

Use the manifest runner for repeatable reporting. The observed native-tool outputs establish the gap: Vale and lychee expose findings, generation emits diagnostics, and pytest summarizes tests, while none supplies the complete ordered project-check record. Keep commands in a reviewed project manifest and native diagnostics in separate logs.

Native commands remain a suitable choice when the consuming CI already produces the required record. Revisit the runner when a project-standard orchestrator supplies equivalent outcomes and provenance.
