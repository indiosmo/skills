# Conflicting-evidence and README-update exercise

Update `readme-before.md` for the Text Workshop target fixture revision using
`source-packet.md` and its linked executable evidence. Produce a short contract,
claim register, README update and review records. Keep proposed behavior and
historical rationale distinct from current behavior. The packet is synthetic;
attributed notes name fixture roles, and establish no real person's approval.

Acceptance requires identifying the obsolete two-input claim, preserving the
single-input contract and exact prepared command, recording the inaccessible
rationale, and avoiding a shipped binary-format or Python-compatibility promise.
The evidence register should make each supplied source kind locatable without
reconstructing the investigation. Existing-site and executable checks are
covered by the separate native fixtures; this exercise targets version/conflict
judgment and a focused README update.
